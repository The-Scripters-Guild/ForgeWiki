While Halo Infinite is an arena shooter, the capabilities of Forge extend beyond simple maps to include campaign experiences, parkour courses, and various minigames.

## Prototyping with Blockouts

A blockout—also referred to as a greybox, whitebox, or prototype map—is the first playable version of a level. It is constructed using basic geometric shapes rather than finished art assets. The primary goal of this phase is to test that gameplay mechanics and player flow work effectively before focusing on visual aesthetics.

### Recommended Primitive Palette

When building initial layouts, it is efficient to use objects from the Halo Design Set and Primitives categories within the Object Browser:

* Cube: `Floors → Floor Half B`
* Triangle: `Floors → Floor Angled Standard A`
* Cylinder: `Primitives → Cylinders → Primitive Cylinder`
* Sphere: `Primitives → Spheres → Primitive Sphere`

## Iteration and Refinement Workflow

To quickly realize layout concepts, designers may utilize a "slopout" phase. This involves creating rough geometry without immediate concern for perfect alignment; this allows the designer to scrap ineffective ideas quickly without having wasted time on detailed refinement.

Once an initial concept is tested and proven functional, the layout should be rebuilt using aligned objects and standard metrics. A thorough rebuild ensures a stable foundation for the final map. 

{% hint style="info" %}
Maintaining attention to standard distances and metrics during the rebuilding phase prevents difficulties later, as it ensures objects follow consistent spacing throughout the level.
{% endhint %}
